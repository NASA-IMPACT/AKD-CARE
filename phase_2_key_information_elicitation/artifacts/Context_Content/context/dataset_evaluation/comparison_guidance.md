# Dataset Comparison Guidance

## Purpose
Enable structured comparison between multiple valid datasets.

## Comparison Dimensions

### Variable Definition
- What is actually measured?
- Is it direct or derived?

### Spatial Resolution
- Does it match the phenomenon scale?

### Temporal Resolution & Extent
- Does it capture required dynamics?
- Are there gaps?

### Processing Level
- Raw vs processed vs modeled

### Instrument & Measurement Method
- Designed for the variable or indirect?

### Coverage
- Continuity
- Missing data

## Output Expectation
- Highlight tradeoffs
- Do not select a single “best” dataset
