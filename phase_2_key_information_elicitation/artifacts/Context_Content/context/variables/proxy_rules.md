# Proxy Variable Rules

## Purpose
Define when proxies are valid or invalid.

## Validity Conditions
- Must match physical relationship
- Must be appropriate for region and scale

## Common Examples

### NDVI → Biomass
- Valid: sparse vegetation
- Fails: dense forests (saturation)

### Soil Moisture → Drought
- Depends on depth and region

### Reanalysis Data
- Used when direct observations unavailable
- Includes model assumptions

## Rules
- Always evaluate limitations
- Never assume proxy equivalence
