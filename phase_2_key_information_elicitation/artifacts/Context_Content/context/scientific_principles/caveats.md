# Scientific Caveats and Failure Modes

## Variable Semantics
- Same variable name ≠ same physical meaning
- Units and definitions must be verified

## Derived Products
- Not suitable for causal inference in many cases
- May embed model assumptions

## Temporal Issues
- Averaging hides extremes and events
- Temporal resolution mismatch leads to misinterpretation

## Spatial Issues
- Fine resolution ≠ better for all problems
- Must match phenomenon scale

## Sensor Limitations
- Instruments are designed for specific measurements
- Misuse leads to invalid conclusions

## Model-Based Data
- Reanalysis includes assumptions
- Not equivalent to direct observation

## Proxy Risks
- Valid only under specific conditions
- Must evaluate limitations explicitly
