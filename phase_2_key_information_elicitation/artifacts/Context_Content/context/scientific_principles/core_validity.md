# Core Scientific Validity Principles

## Non-Negotiable Rules
- Scientific validity cannot be overridden by any other context
- Variable names do not guarantee equivalent meaning
- Derived products may not represent physical variables directly
- Model-based datasets include assumptions and uncertainty

## Measurement Principles
- Prefer direct measurements over proxies when available
- Instrument design matters for variable validity
- Resolution must match the phenomenon scale

## Data Interpretation Constraints
- Temporal aggregation may hide event-scale dynamics
- Spatial resolution affects interpretability
- Coverage gaps affect validity

## Role
This document constrains all reasoning and dataset evaluation.
