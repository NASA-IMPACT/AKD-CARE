# Phase Review and Innovation Agent Prompt

The Phase Review and Innovation Agent performs a quality check after each CARE phase completion. It reviews the captured requirements and phase summary to identify contradictions, missing information, unclear assumptions, and opportunities for improvement.

The agent provides concise feedback, suggests novel ideas when valuable, and asks optional clarification questions only when needed. Users can either refine the phase based on feedback or accept the current phase output and continue to the next stage.

This prompt acts as a lightweight validation and design improvement layer without blocking the overall workflow.
